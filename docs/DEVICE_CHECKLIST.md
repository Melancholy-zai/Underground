# 真机与正式资料验收清单

以下为待执行验收，不代表已通过。记录 iPhone 型号、iOS 版本、高德/百度版本、城市资料版本、测试日期、实际起终点与截图。

## 安装与离线

- [ ] 使用个人 Team 真机签名安装成功；签名失效后能从 Xcode 重新安装。
- [ ] 打开后不出现定位授权弹窗。
- [ ] 飞行模式下冷启动，地图/线路列表/中文与拼音搜索/站点详情均可用。
- [ ] 定位关闭时手动选择起终点，App 不强行请求定位。
- [ ] 在线与离线显示的是同一城市资料版本，无暗中联网取数据。

## 线网与行政区

- [ ] 以明确 dataAsOf 日期核对所有已开通区段、全部站名、官方线路色、全线终点和换乘关系。
- [ ] 不混入在建、规划、城际、国铁和有轨电车。
- [ ] 各站行政归属有来源；边界、特殊管理区域用多归属或说明表达。
- [ ] 完整线网在小屏 iPhone 上，放大后能清楚看站名；区块边界不穿错归属。
- [ ] 线路高亮、线路列表、空白清除正确。
- [ ] 换乘站附近点站优先；拖动/捏合后不弹详情。
- [ ] 搜索居中在键盘收起后保持；横竖屏变化不丢失所选站点。
- [ ] 恢复全图可回到所有站点可见状态，手势持续操作不卡顿。
- [ ] VoiceOver 可读站点，字号放大时原生资料卡与路线页仍可操作。

## 站点资料

- [ ] 随机抽查每条线、每个方向的本站首末班，不用全线时段替代。
- [ ] 工作日/休息日/节假日/季节等仅在来源支持时录入；有效期完整。
- [ ] 跨午夜显示“次日”，特殊末班实际终点有标注。
- [ ] 出口编号和道路/地标来自核实资料；无资料显示“暂无资料”。
- [ ] 过期时刻有提示，来源与更新时间可见。
- [ ] 不承诺出口当前开放或列车实时状态。

## 定位与导航（高德、百度分别执行）

- [ ] 先手选 A 站→B 站，打开地图后起点仍为 A，终点 B，默认公交。
- [ ] 交换后 B→A，外部参数和结果一致。
- [ ] 选择同站，App 提示重选，不发起外部规划。
- [ ] 默认“当前位置”不立即申请权限；点击使用功能后才申请。
- [ ] 允许定位，外部地图起点与现场位置一致；终点正确。
- [ ] 拒绝/限制定位后提示可手选；手选后仍能规划。
- [ ] 定位等待期间换成手动起点，迟到回调不能覆盖/打开旧路线。
- [ ] 连续取消并重新定位，旧取消回调不会取消新请求。
- [ ] 离开路线页时尚未完成的请求不在后台自动打开地图。
- [ ] 站点“从当前位置步行到本站”明确使用当前位置和步行模式。
- [ ] 出口精确坐标可导航，缺坐标出口不显示精确导航按钮。
- [ ] WGS84 参数在两个外部 App 中均落在正确位置。
- [ ] 高德手动站点起点使用GCJ02坐标（dev=0）；当前位置使用WGS84（dev=1），站点终点由POI编号解析。
- [ ] 高德缺少可靠起点位置时显示错误，不调起名称不确定的路线；百度名称匹配仍需核对城市与站点。
- [ ] 未安装、卸载、打开失败时提示明确，可选择另一地图。

## 城市包更新

- [ ] Python 校验通过；非样本包触发正式资料检查，缺人工依据应失败。
- [ ] 修改 JSON/SVG 任一文件而不更新 manifest，App 拒绝加载。
- [ ] 整包更新后版本/截止日期正确，图中所有站点可打开对应详情。
- [ ] 不需要任何自建后端，核心流程仍能工作。
