## 数据约定

- `timetables-reviewed.csv` 保留开关站时间、各方向首末班与半程末班原值。开关站时间仅进审计层，不当作列车首末班。
- 4 号线适用条件原文为“平日和周末”；13 号线原图没有说明适用日，字段明确写“来源未注明适用日”。
- 横线保留在原始层。始发终点站本身方向为 `notApplicable`，不生成虚假 00:00 时刻。
- 表中 00:xx 末班按照次日表示；显示时钟与 `dayOffset` 分开。全程、半程目的地分开存储。
- 时刻 ID 按站点、线路、方向、适用条件、服务类型及目的地构造，不含时刻值。
- 每站 `audit.rawTimetableRow` 保留原值、原站名、表内行号、方向列定义和来源 URL/路径/SHA/访问日期/发布时间原值/核验日期。
- `audit.rawExitTranscription`、`mapExitNumbers`、`mapOnlyExitNumbers`、`mapExitAnnotations` 保留出口核读依据；`exitResolution` 记录编号差异处理。

## 重建与验证

```sh
python3 tools/collect_operator_services.py --fetch
python3 tools/collect_operator_services.py --build
```

`--fetch` 顺序请求，间隔 0.7 秒，每次请求超时 30 秒；复用已成功缓存，失败请求记录后不自动重试或绕过访问限制。`--build` 离线读取已核读摘录，先验证来源图片哈希，图片变化即报错要求重新核读。

已实际执行离线重建，输出 49 站 / 117 条时刻 / 292 个出口；检查所有事实 ID 唯一、来源引用存在、101 张图片均有核读状态、未知生效日期为 null。工作区没有 Git 仓库，因此不能用 `git diff --check` 验证。

仍需由全网合并阶段比较其他官方来源的同方向、同条件时刻；本导入不以来源优先级静默覆盖矛盾。未穷尽临时运营公告，未确认出口实时开放，也没有出口经纬度；各站服务状态因此保留 partial。
