# 深铁分区图 · 实现设计

用户提供的十节需求大纲是产品范围；用户已要求直接从零生成代码。本设计采用其中的默认行为，不增加账户、后端、实时信息或内部路线计算。

## 可交付物与诚实边界

交付能在 Xcode 构建的 iPhone App、独立 Swift 业务模块、Python 城市包生成校验工具、自动化测试、中文运行与资料制作文档。最低 iOS 17，无第三方运行时依赖。工作区原为空且没有 Git 仓库，直接在该目录创建文件，不创建无意义的 worktree，也不自动提交。

用户尚未提供经核实且可复用的全深圳线网、出口、时刻与 SVG。内置包标记 sample，展示局部开发样本；不得将其说成完整运营网络。所有未经核实的时刻、出口、真实坐标留空。正式包必须通过 production 校验，包含来源、截止日、人工覆盖范围核验记录。生产核验不能仅靠程序推断。

## 架构

- MetroCore：Codable 数据、加载校验、站名/拼音搜索、首末班服务日表示、路线状态、URL 构造。Foundation-only，可用 swift test 在 Mac 运行。
- App：SwiftUI 三页（地图、路线、资料），WKWebView 加载本地 SVG，CoreLocation 按需一次定位，UIApplication 调起外部地图。
- data/shenzhen/source.json：手工维护的业务资料及示意坐标。Python 生成 city.json、map.svg 和 manifest.json，后者绑定二者 SHA-256；App 加载时校验配套关系。
- 真实坐标与示意坐标是两个不同类型。第一版导航统一使用经核验的 WGS84。工具拒绝误标的其他坐标系，不自制近似转换；缺坐标时站点可按包含城市的站名交给外部地图确认，出口只允许已核实坐标。

## 交互与错误

地图在浅色行政区块上绘制独立线路与站点对象；SVG ID 固定。拖拽/捏合、缩放按钮、全图恢复、线路列表高亮、空白清除、站点优先命中、搜索居中、原生站点卡片。Web 内容只允许本地资源，无远程脚本；原生侧验证所有消息 ID。

路线初始起点是当前位置，只有点击外部地图或“获取当前位置”时请求定位。异步定位以请求令牌与路线快照保护，编辑或切换页面后不能自动发起旧路线。手选站点不会被定位覆盖。两站可交换，同站拒绝。站点“导航到这里”明确切换当前位置作为起点和步行方式；“设为终点”保留手选起点并使用公交。

站点卡按线路逐一展示时刻与缺失状态，服务日分类、有效期、次日、实际终点、来源和更新时间。入口、行政区特殊归属可用备注表达。资料包损坏显示可恢复错误页，不崩溃或悄悄载入不匹配文件。

## 验证

Swift 测试覆盖同站、交换、中文 URL、手动起点、坐标体系、跨午夜、无效资料与本地搜索。Python 测试覆盖 ID、引用、SVG/JSON 一致性、数据缺失、生产门槛。Xcode 模拟器构建和 UI 测试覆盖打开地图、搜索详情、设起终点和切页。高德/百度实际接收与真实设备定位必须留作真机验收，不得将 URL 单测当成真机通过。
